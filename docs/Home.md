# mindas terminal wiki

A universal terminal for Windows and Linux. Real shells (bash first, also on Windows), tabs and split panes,
vim-style copy mode, a task manager with GPU use, and offline toolkits of curated commands for eleven fields.

## Principles

- **Your machine, your data.** No telemetry, no network access by the app, scrollback in memory only.
- **Nothing runs by surprise.** Toolkit commands are inserted, not run. Multi-line pastes that would run ask first.
- **Same habits everywhere.** Bash first on Windows too; Linux command names in PowerShell if you want them.
- **For ethical use.** Built for defenders, engineers, researchers and learners. See [Security](Security).
